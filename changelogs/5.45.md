## Fixes

# 5.45.1
Released 31st October 2026.

- Fixed players failing to log in when the JWT audience claim is sent as an array.
- Reduced per tick and network overhead: the block palette is streamed instead of decoded as a whole NBT tree, living entities and world random ticks do less work per tick, packet broadcasts are encoded in a single pass and spawn packets that never change are reused.
- Fixed NetherNet signalling connections never timing out.
- Fixed NetherNet media traffic on unrouted UDP ports not being handled.
- Fixed NetherNet sessions timing out while the client is still loading, SCTP traffic now keeps them alive.
- NetherNet media now shares the server port by default ('network.nethernet.udp-port: 0'), so no extra port has to be forwarded. Query is served on that port too. Set it to -1 to give each player a port of their own.
- Added IPv6 support for NetherNet joins. With 'enable-ipv6' on, the join endpoint also listens on 'server-ipv6'.
