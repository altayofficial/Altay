# 5.45.0
Released 27th October 2026.

## General
- Added support for Minecraft: Bedrock Edition 1.26.60 (display version 26.60). (@xRookieFight)
- Removed support for earlier versions.

## Fixes
- Capped armor points in damage reduction.

# 5.45.1
Released 31st October 2026.

- Fixed players failing to log in when the JWT audience claim is sent as an array.
- Reduced per tick and network overhead: the block palette is streamed instead of decoded as a whole NBT tree, living entities and world random ticks do less work per tick, packet broadcasts are encoded in a single pass and spawn packets that never change are reused.
- Fixed NetherNet signalling connections never timing out.
- Fixed NetherNet media traffic on unrouted UDP ports not being handled.
- Fixed NetherNet sessions timing out while the client is still loading, SCTP traffic now keeps them alive.
- NetherNet media now shares the server port by default ('network.nethernet.udp-port: 0'), so no extra port has to be forwarded. Query is served on that port too. Set it to -1 to give each player a port of their own.
- Added IPv6 support for NetherNet joins. With 'enable-ipv6' on, the join endpoint also listens on 'server-ipv6'.

# 5.45.2
Released 14th November 2026.

## Security
- Fixed a pre-authentication server crash caused by a login JWT whose ES384 signature has an all zero R or S value. Such logins are now rejected with the usual invalid session disconnect. Credit to @NaySurGithub.

## Fixes
- Fixed shulker box contents being duplicated when dyeing a shulker box.
- Fixed recipe IDs being sent as packed bytes, which produced invalid UTF-8 strings once a recipe network ID reached 128. They are now sent as decimal strings.
- Fixed disconnect packets being lost when they were queued behind pending compression. Sessions now drain their queue before the transport is closed, with a timeout.
- Updated altayofficial/network to 1.6.1 and altayofficial/webrtc to 1.9.2, which pace NetherNet ICE connectivity checks.
